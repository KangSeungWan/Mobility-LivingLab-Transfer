# 통학길 비교 · 대전 (C.A.W 모빌리티리빙랩 1조) — 실시간 API 버전

실시간 버스 도착정보와 카카오맵으로, 지금 출발하면 버스·지하철·타슈·택시 경로마다 **몇 시에 도착하는지** 비교하는 웹사이트입니다.

- **경로 비교**: 출발지(공대 3호관 · 궁동 욧골공원 · 학사마을 · 충대서문) → 대전역 A~E 경로. 노선·환승역·구간 시간은 카카오 대중교통·도보·자전거 길찾기, 버스 대기는 실시간·열차 대기는 시각표. A(버스+지하철)의 실제 요금보다 추가 비용 없이 A보다 빨리 도착하는 경로 중 가장 빠른 경로에 '추천'(없으면 A, A 요금 미확인이면 보류).
- **주변 정류장 실시간**: 출발 위치 근처 정류장의 도착 예정 버스와 "지금 가면 탑승 / 놓침". 대전 어디서든 동작.
- **API 점검** (`/health.html`): 키마다 실제로 호출해 보고 정상 여부와 원본 응답을 보여 줌.

---

## 시작하기 (순서대로)

### 1. 키 확인
`.env.example`을 복사해 이름을 `.env`로 바꾸고, 각자 발급받은 키(공공데이터포털, 카카오 REST, 타슈)를 넣으세요. **`.env`는 절대 커밋하지 마세요** (`.gitignore`로 제외됨).

- **카카오 JavaScript 키**(선택): 같은 카카오 앱의 '앱 키' 화면에 있습니다. `.env`의 `KAKAO_JS_KEY`에 넣으면 카카오 지도, 비워 두면 OpenStreetMap 지도가 뜹니다. 넣었다면 플랫폼 → Web → 사이트 도메인에 `http://localhost:3000` 등록.
- 카카오 REST 키 → 장소 검색, 택시 시간·요금(카카오모빌리티 길찾기), 대중교통·도보·자전거 경로 조회(카카오맵 REST — 앱 관리 > [카카오맵] > [사용 설정] ON 필요, 각각 하루 무료 1,000건).
- 타슈 키 → 출발지 근처 대여소의 실시간 자전거 수 (D·C 경로에 반영).

### 2. 실행
Node.js 18 이상 필요 (nodejs.org LTS). 설치할 패키지는 없습니다.

```bash
npm start        # → http://localhost:3000
```

### 3. API 점검 → 결과 보내기
`http://localhost:3000/health.html` → **점검 시작** → 결과를 확인하고, 빨간 항목이 있으면 **결과 전체 복사**해서 보내 주세요. 키는 ***로 가려집니다.

| 점검 항목 | 실패하면 |
|---|---|
| TAGO 버스정류소정보 | 팀원 계정에서 '국토교통부_(TAGO)_버스정류소정보' 활용신청. 그 전에는 아래 4번 예비 정류장 사용 |
| TAGO 버스도착정보 | 키 확인 (Decoding 키인지) |
| 대전시 정류소별 도착정보 | 정류장 번호 칸에 실제 번호를 넣고 다시 점검 |
| 카카오 로컬 장소 검색 | REST 키, 앱의 카카오맵 사용 설정 확인 |
| 카카오모빌리티 길찾기 | 권한이 없으면 실패가 정상 — 택시는 고정값으로 계산 |
| 카카오 대중교통 경로 조회 | 앱 관리 > [카카오맵] 사용 설정 ON, 하루 무료 1,000건. 실패하면 공대 3호관은 108번 고정 경로, 다른 출발지는 추정값 |
| 카카오 탑승 정류장 ↔ TAGO 정류장 연결 | 이름이 같은 정류장(★)과 진행방향 오른쪽/왼쪽이 나옴. 방향을 확인한 정류장 ID는 `scenario.js`의 `bus.verifiedStops`에 **노선별로** 입력 (노선+정류장 조합으로 판정) |
| 카카오 도보·자전거 경로 조회 | 카카오맵 사용 설정 확인. 실패하면 타슈 구간은 고정값·추정값 |
| 출발지 좌표 확인 | 4곳 모두 2026-11-17 확인됨. 새 출발지를 넣을 때 맞는 장소의 좌표를 `public/scenario.js`의 `origins`에 넣고 `verified: true` |
| 타슈 대여소 실시간 | 타슈 키 확인 |
| 열차시각표 (테스트 주소) | `.env`의 `DJ_SUBWAY_TEST_URL`을 넣었을 때만 실행 |

### 4. 정류장·노선 방향 (scenario.js)
- `bus.verifiedStops`: 노선 번호 → 방향을 확인한 TAGO 정류장 ID. 확인된 조합(예: 108번 DJB8005589)만 '방향 확인됨'이고, 그 밖의 노선은 다른 노선이 확인된 정류장이라도 '미확인'으로 추천하지 않음.
- 현재 확인값(2026-11-17): 108번 42630·42650, 102·106·706번 42680(다솔아파트), 704·708번 42130(궁동교)·42540(충대서문).
- `bus.stopIds`·`bus.arsStops`: 카카오 대중교통 길찾기를 못 쓸 때 공대 3호관의 108번 고정 경로에서만 사용.

### 5. 요금 (scenario.js `fare`)
- 공식 요금표(대전교통공사·타슈) 기준. 지하철 1구간(승차역에서 10㎞ 이내) 1,550원·2구간 1,650원, 시내·마을버스+지하철 환승 합계 1,550/1,650원, 타슈 1시간 무료·초과 30분당 500원.
- A 요금 = 카카오 안내 요금(요금이 다른 버스가 섞이면 일반·마을버스 기준 최저 요금, 좌석버스는 탈 노선에서 제외). 지하철 구간은 `subway.zoneConfirmed` 또는 카카오 요금 대조로만 확정.

## 링크로 공유하기 (Vercel, 무료)
1. 저장소를 GitHub에 올림 (`.env`는 자동 제외)
2. vercel.com → Add New Project → 저장소 → Root Directory `cnu-route-web`, Framework Preset **Other**, Output Directory `public`
3. Environment Variables에 `.env`와 같은 이름·값 입력 → Deploy
4. 생긴 주소(`https://xxx.vercel.app`)를 카카오 Web 도메인에 추가

## 실시간 / 가정값 구분
- **실시간**: 버스 도착(TAGO 또는 대전시), 타슈 대여소 자전거 수, 택시(카카오모빌리티 길찾기)
- **카카오 길찾기**: 경로 구성(노선·정류장·환승역), 구간별 도보·버스 승차·타슈 주행 시간 (카카오 전체 소요시간은 대기가 들어 있어 쓰지 않음, 카카오 결과(검색·택시 포함)는 재사용 캐시 없음)
- **시각표**: 지하철 대기·소요시간 (대전교통공사 열차시각표, 평일·휴일 구분)
- **가정값** (`scenario.js`에서 수정): 역내 이동 3분, 택시 대기 4분, 타슈 대여·반납 1분, 버스를 놓쳤을 때 다음 차 간격 15분, 탑승 최소 여유 1분, 길찾기 실패 시 고정값·추정값
- 가정값·추정값·미확인 정보가 섞인 경로는 '가정값 포함'으로 표시하고 추천하지 않음
- 화면의 각 단계에 '실시간' 표시가 붙어 구분됩니다.

## 키가 없을 때
`.env` 없이 실행하면 예시 데이터 모드로 화면만 확인할 수 있습니다.

## 폴더 구조
```
api/          서버 함수 (stops, arrivals, arrivals-dj, subway, drive, search, transit, walk, bike, tashu, config, health)
lib/core.js   공공데이터·카카오 호출, 오류 해석, 예시 데이터
public/       웹페이지 (index.html, app.js, style.css, scenario.js, health.html)
server.js     로컬 실행용 서버
../tests/offline.cjs  오프라인 검증 (모의 응답, 외부 호출 없음) — 저장소 루트에서 `node tests/offline.cjs`
```
