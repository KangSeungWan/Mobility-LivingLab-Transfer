# 통학길 비교 · 대전 (C.A.W 모빌리티리빙랩 1조) — 실시간 API 버전

실시간 버스 도착정보와 카카오맵으로, 지금 출발하면 버스·지하철·타슈·택시 경로마다 **몇 시에 도착하는지** 비교하는 웹사이트입니다.

- **경로 비교**: 공대 3호관 → 대전역 A~E 경로. 108번 버스 대기는 실시간, 버스+지하철 요금 안에서 가장 빨리 도착하는 경로에 '추천'.
- **주변 정류장 실시간**: 출발 위치 근처 정류장의 도착 예정 버스와 "지금 가면 탑승 / 놓침". 대전 어디서든 동작.
- **API 점검** (`/health.html`): 키마다 실제로 호출해 보고 정상 여부와 원본 응답을 보여 줌.

---

## 시작하기 (순서대로)

### 1. 키 확인
`.env.example`을 복사해 이름을 `.env`로 바꾸고, 각자 발급받은 키(공공데이터포털, 카카오 REST, 타슈)를 넣으세요. **`.env`는 절대 커밋하지 마세요** (`.gitignore`로 제외됨).

- **카카오 JavaScript 키**(선택): 같은 카카오 앱의 '앱 키' 화면에 있습니다. `.env`의 `KAKAO_JS_KEY`에 넣으면 카카오 지도, 비워 두면 OpenStreetMap 지도가 뜹니다. 넣었다면 플랫폼 → Web → 사이트 도메인에 `http://localhost:3000` 등록.
- 카카오 REST 키 → 장소 검색. 택시 시간·요금은 카카오모빌리티 길찾기 **권한이 있을 때만** 실시간이고, 없으면 고정값.
- 타슈 키 → 출발지 근처 대여소의 실시간 자전거 수 (D·C 경로에 반영).

### 2. 실행
Node.js 18 이상 필요 (nodejs.org LTS). 설치할 패키지는 없습니다.

```bash
npm start        # → http://localhost:3000
```

### 3. API 점검 → 결과 보내기
`http://localhost:3000/health.html` → **점검 시작** → 결과를 확인하고, 빨간 항목이 있으면 **결과 전체 복사**해서 보내 주세요. 키는 ***로 가려집니다.

| 점검 항목 | 실패하면 |
|---|---|
| TAGO 버스정류소정보 | 팀원 계정에서 '국토교통부_(TAGO)_버스정류소정보' 활용신청. 그 전에는 아래 4번 예비 정류장 사용 |
| TAGO 버스도착정보 | 키 확인 (Decoding 키인지) |
| 대전시 정류소별 도착정보 | 정류장 번호 칸에 실제 번호를 넣고 다시 점검 |
| 카카오 로컬 장소 검색 | REST 키, 앱의 카카오맵 사용 설정 확인 |
| 카카오모빌리티 길찾기 | 권한이 없으면 실패가 정상 — 택시는 고정값으로 계산 |
| 타슈 대여소 실시간 | 타슈 키 확인 |
| 열차시각표 (테스트 주소) | `.env`의 `DJ_SUBWAY_TEST_URL`을 넣었을 때만 실행 |

### 4. 정류장 지정 (꼭 한 번)
`public/scenario.js`에서:
- 근처 정류장 API가 **되면**: '주변 정류장' 탭에서 **월평역 방면** 정류장 ID를 확인해 `bus.stopIds`에 넣기 (반대 방향 정류장이 섞이지 않게).
- 근처 정류장 API가 **안 되면**: `bus.arsStops`에 108번 타는 정류장의 **5자리 정류장 번호**(정류장 표지판 또는 카카오맵 정류장 정보)와 좌표를 넣기 → 대전시 도착정보로 실시간 조회.

### 5. 지하철 시각표 연결 (다음 단계)
공공데이터포털 → 대전교통공사_열차시각표 → 미리보기에서 월평역으로 호출한 **요청 주소**를 `serviceKey` 부분만 빼고 `.env`의 `DJ_SUBWAY_TEST_URL`에 넣고 점검하면, 원본 응답이 나옵니다. 그 결과를 보내 주시면 '10분 간격 가정'을 실제 시각표 계산으로 바꿉니다.

## 링크로 공유하기 (Vercel, 무료)
1. 저장소를 GitHub에 올림 (`.env`는 자동 제외)
2. vercel.com → Add New Project → 저장소 → Root Directory `cnu-route-web`, Framework Preset **Other**, Output Directory `public`
3. Environment Variables에 `.env`와 같은 이름·값 입력 → Deploy
4. 생긴 주소(`https://xxx.vercel.app`)를 카카오 Web 도메인에 추가

## 실시간 / 가정값 구분
- **실시간**: 버스 도착(TAGO 또는 대전시), 타슈 대여소 자전거 수·도보 거리, 택시(카카오 길찾기 권한이 있을 때)
- **시각표**: 지하철 대기·소요시간 (대전교통공사 열차시각표, 평일·휴일 구분)
- **가정값** (`scenario.js`에서 수정): 도보·타슈·역내 이동, 버스를 놓쳤을 때 다음 차 간격, 탑승 최소 여유 1분
- 화면의 각 단계에 '실시간' 표시가 붙어 구분됩니다.

## 키가 없을 때
`.env` 없이 실행하면 예시 데이터 모드로 화면만 확인할 수 있습니다.

## 폴더 구조
```
api/          서버 함수 (stops, arrivals, arrivals-dj, subway, drive, search, tashu, config, health)
lib/core.js   공공데이터·카카오 호출, 오류 해석, 예시 데이터
public/       웹페이지 (index.html, app.js, style.css, scenario.js, health.html)
server.js     로컬 실행용 서버
```
