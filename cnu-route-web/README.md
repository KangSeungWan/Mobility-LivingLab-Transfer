# 통학길 비교 · 대전 (C.A.W 모빌리티리빙랩 1조) — 실시간 API 버전

실시간 버스 도착정보와 카카오맵으로, 지금 출발하면 버스·지하철·타슈·택시 경로마다 **몇 시에 도착하는지** 비교하는 웹사이트입니다.

- **경로 비교**: 출발지(공대 3호관 · 궁동 욧골공원 · 학사마을 · 충대서문) → 대전역. 카카오 대중교통 길찾기 경로를 실시간 버스 도착·열차시각표로 다시 계산한 일반 대중교통(최대 5개), 전 구간 택시·타슈, 근처 지하철역별로 계산한 타슈·택시 연계 복합경로(유형별 1개 — 추가 비용 허용 범위 안에서 가장 빠른 후보, 없으면 가장 빠른 후보를 '범위 초과'로 표시·추천 제외)를 도착 순으로 비교. 비교 기준(확인된 가장 빠른 대중교통) 요금 + 추가 비용 허용 범위(0/3,000/7,000/상관없음) 안에서 가장 빠른 경로에 '추천'. 추가 비용은 직접 입력도 가능(0~50,000원 정수, 쉼표·'원' 허용, 잘못된 값은 거절하고 직전 설정 유지, 바꿔도 API 재호출 없음). 버스 운행 방향은 TAGO 버스노선정보로 자동 확인.
- **주변 정류장 실시간**: 출발 위치 근처 정류장의 도착 예정 버스와 "지금 가면 탑승 / 놓침". 대전 어디서든 동작.
- **API 점검** (`/health.html`): 키마다 실제로 호출해 보고 정상 여부와 원본 응답을 보여 줌.

## 시작하기 (순서대로)

### 1. 키 확인
`.env.example`을 복사해 이름을 `.env`로 바꾸고, 각자 발급받은 키(공공데이터포털, 카카오 REST, 타슈)를 넣으세요. **`.env`는 절대 커밋하지 마세요** (`.gitignore`로 제외됨).

- **카카오 JavaScript 키**(선택): 같은 카카오 앱의 '앱 키' 화면에 있습니다. `.env`의 `KAKAO_JS_KEY`에 넣으면 카카오 지도, 비워 두면 OpenStreetMap 지도가 뜹니다. 넣었다면 플랫폼 → Web → 사이트 도메인에 `http://localhost:3000` 등록.
- 카카오 REST 키 → 장소 검색, 택시 시간·요금(카카오모빌리티 길찾기), 대중교통·도보·자전거 경로 조회(카카오맵 REST — 앱 관리 > [카카오맵] > [사용 설정] ON 필요, 각각 하루 무료 1,000건).
- 타슈 키 → 출발지 근처 대여소의 실시간 자전거 수 (D·C 경로에 반영).

### 2. 실행
Node.js 18 이상 필요 (nodejs.org LTS). 설치할 패키지는 없습니다.

```bash
npm start        # → http://localhost:3000
```

### 3. API 점검 → 결과 보내기
`http://localhost:3000/health.html` → **점검 시작** → 결과를 확인하고, 빨간 항목이 있으면 **결과 전체 복사**해서 보내 주세요. 키는 ***로 가려집니다.

### 4. 정류장·노선 방향
- **자동 확인 (update12, 우선)**: 서버 `/api/busroute?routeNo=`가 TAGO 버스노선정보(노선번호목록 → 노선별 경유 정류장, 페이지 끝까지)를 받아 완전한 목록일 때만 1일 캐시해 줍니다. 완전성 검사: 전체 건수(totalCount)가 0 이상 정수(숫자 또는 숫자 문자열)이고 쪽마다 같으며(null·빈 값·음수·소수 등은 정상 0건으로 보지 않음), 쪽 번호가 맞으며 같은 쪽 반복·덜 찬 중간 쪽이 없을 것(어긋나면 502), 노선마다 필수 항목·순번(1 이상 정수, 중복·빈칸 없음)·상하행 코드 구간(바뀜 1번 이하)이 정상일 것, 노선 ID가 6개 이하이고 조회한 번호와 같은 행에 노선 ID(routeid)가 모두 올바르게 있을 것(누락·빈 값·문자열 'null'·'undefined'는 불량 — 도착정보의 이런 노선 ID는 방향 대조에 쓰지 않음). 하나라도 어긋나면 `complete:false`로 돌려주고 서버·CDN·브라우저 어디에도 저장하지 않습니다(순환노선의 같은 정류장 ID·다른 순번은 정상). 화면은 카카오 버스 구간의 승차·하차 정류장을 이름 + 80m 안 좌표로 공식 정류장에 맞춘 뒤, ① 같은 상하행 구간 안에서 승차 → 하차 순서 ② 사이 정류장 수(±15%)·이름 순서(60% 이상) 일치 ③ 승차 정류장 중복 경유(순환·회차) 없음 ④ 같은 번호의 노선 ID들에서 승차 정류장이 하나로 정해짐 — 을 모두 만족할 때만 '자동 확인'. 실시간 차량은 TAGO 도착정보의 노선 ID가 확인된 노선 ID와 같을 때만 그 방향으로 봅니다(대전시 보조 도착정보 차량은 '미확인'). 순번(승차 < 하차)만으로는 확정하지 않습니다.
- 한 경로에 확인된 노선과 미확인 노선이 같이 있으면 미확인 노선 차량은 먼저 와도 타지 않습니다.
- `bus.verifiedStops` (scenario.js, 보조): 노선 번호 → 방향을 확인한 TAGO 정류장 ID. 공식 정보를 확보하지 못했을 때만(조회 실패·공식 노선 없음·불완전 목록·조회 상한) '수동 확인'으로 씁니다. 완전한 공식 목록이 방향을 거부하면(승·하차 순서 불일치·순환·승차 후보 둘 이상) 목록에 있어도 확인 상태를 주지 않고, 공식 노선 정보와 다른 정류장을 가리키면 충돌로 봅니다. 다른 노선의 확인으로 승격하지 않습니다.
- 현재 확인값(2026-11-17): 108번 42630·42650, 102·106·706번 42680(다솔아파트), 704·708번 42130(궁동교)·42540(충대서문).
- `bus.stopIds`·`bus.arsStops`: 카카오 대중교통 길찾기를 못 쓸 때 공대 3호관의 108번 고정 경로에서만 사용.

### 5. 요금 (scenario.js `fare`)
- 공식 요금표(대전교통공사·타슈) 기준. 지하철 1구간(승차역에서 10㎞ 이내) 1,550원·2구간 1,650원, 시내·마을버스+지하철 환승 합계 1,550/1,650원, 타슈 1시간 무료·초과 30분당 500원.
- 일반 대중교통 요금 = 카카오 안내 요금(요금이 다른 버스가 섞이면 공식 환승 규정·일반·마을버스 기준, 좌석버스는 탈 노선에서 제외). 지하철 구간은 `subway.zoneConfirmed`(월평·갈마 1구간, 유성온천·갑천 2구간 — 갑천→대전역은 카카오 지하철 10.1㎞·1,650원으로 확인) 또는 카카오 요금 대조로만 확정.

## 링크로 공유하기 (Vercel, 무료)
1. 저장소를 GitHub에 올림 (`.env`는 자동 제외)
2. vercel.com → Add New Project → 저장소 → Root Directory `cnu-route-web`, Framework Preset **Other**, Output Directory `public`
3. Environment Variables에 `.env`와 같은 이름·값 입력 → Deploy
4. 생긴 주소(`https://xxx.vercel.app`)를 카카오 Web 도메인에 추가

## 실시간 / 가정값 구분
- **공식 노선 정보**: 버스 운행 방향 자동 확인(TAGO 버스노선정보, 완전한 목록만 서버 1일 캐시)
- **실시간**: 버스 도착(TAGO 또는 대전시), 타슈 대여소 자전거 수, 택시(카카오모빌리티 길찾기)
- **카카오 길찾기**: 경로 구성(노선·정류장·환승역), 구간별 도보·버스 승차·타슈 주행 시간 (카카오 전체 소요시간은 대기가 들어 있어 쓰지 않음, 카카오 결과(검색·택시 포함)는 재사용 캐시 없음)
- **시각표**: 지하철 대기·소요시간 (대전교통공사 열차시각표, 평일·휴일 구분)
- **가정값** (`scenario.js`에서 수정): 역내 이동 3분, 택시 대기 4분, 타슈 대여·반납 1분, 버스를 놓쳤을 때 다음 차 간격 15분, 탑승 최소 여유 1분, 길찾기 실패 시 고정값·추정값
- 가정값·추정값·미확인 정보가 섞인 경로는 '가정값 포함'으로 표시하고 추천하지 않음
- 화면의 각 단계에 '실시간' 표시가 붙어 구분됩니다.

## 키가 없을 때
`.env` 없이 실행하면 예시 데이터 모드로 화면만 확인할 수 있습니다.
